# ArasakaNet
A website that mimics a linux-like os, or does it?
A lightweight web desktop inspired by Cyberpunk 2077. Built entirely with vanilla HTML, CSS, and JavaScript.
---

## Features

- Draggable Windows: Drag windows across the desktop using their header bars.
- Stacking System: Clicking any window brings it directly to the front.
- Start Menu: Toggle the sidebar menu on and off via the taskbar logo.
- NASA Control Panel: A link hub connecting to NASA's space APIs and websites.
- Countdown Timer: Timer with custom inputs, pause, and reset controls.
- Live Clock: Time updater running in real time in the bottom panel.
